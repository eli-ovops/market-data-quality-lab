# 香港盈立：个人自有程序与美股行情/交易准入

结论：**官方确有面向个人投资者的OpenAPI，不能说只供机构，或把它降为仅有条件单。** 但用户具体账户接入资格、实时美股行情的程序化/非展示研究授权和费用尚未闭合，不能因已有香港账户或约5kUSD就宣布现在可用模型实盘。未登录/申请/接钱包/试接口，本轮仅公开文档读取。

## 1. 任意自有程序有官方开发接口依据，实际权限仍需账户授权

[官方开发文档入口](https://www.usmart.hk/mainland/zh-cn/docs/) L13–29明确OpenAPI面向individual and institutional investor，提供交易/行情/账户服务，支持开发自己的投资应用；申请只向已开户且有资产客户开放。普通账户支持美股/港股/A股，文档称普通账户只能交易时段下单、PRO可随时提交，不代表随时成交或所有盘前盘后功能都已核。

[官方OpenAPI FAQ](https://hk.usmartglobal.com/en/helpframe/199/detail/10851) L164–205明确美股交易及行情、HTTP接口与HTTP/WebSocket长连接、语言不限；用户需申请接口权限并签API授权协议。它声明当前没有资产及交易频率门槛，但仍需资格审批与协议，并非匿名公开下单接口。用户账户是否有资产/何种账户/是否已经授权，以及常住内地对该接口资格的影响，本轮没有核到，不读取账号猜测。

所以“个人可以申请开发自己的程序”有官方依据；“本用户现在可以让自己的模型获取合规实时行情并执行”仍为UNKNOWN。此处完全基于OpenAPI文本，不依赖TradingView接入、智能条件单或TWAP/VWAP产品来推导开发能力。

## 2. 行情服务存在，实时美股内容、时延及模型研究权利未明确

FAQ确称支持US Stock quotes，但被问到即时/历史行情时，只列临时K线额度：普通账户10股各200条、PRO50股各200条，并说可能调整。这不是完整逐笔/盘口服务定义，不能据此推实时NBBO、深度、时间戳含义、延迟秒数或程序可持续推送能力。官网首页免费串流及申请页speedy报价的搜索摘要也不能填补API具体行情授权。

开发文档入口实际给出Basic Quotes Open API、Quote push access protocol，但两个链接分别落到：

- https://www.usmart.hk/quote-base.html ：本轮原生404。
- https://www.usmart.hk/quote-push.html ：本轮原生404。

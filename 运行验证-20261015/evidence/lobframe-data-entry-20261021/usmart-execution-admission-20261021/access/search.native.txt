uSMART Securities Open API can provide API services for individual and institutional investor, investors can make full use of uSMART Securities trading services, quotes services, account services and so on to achieve their own investment applications.

  * Regular customers can apply through the following link：https://www.usmart.hk/zh-hk/open-api。

uSMART Securities also provides Open API custom development services, the cost depends on the development workload. For customers with high hardware requirements, uSMART Securities can also provide server rental.

# A股又現窗口指導，為什麼量化交易成為眾矢之的？

格隆匯 09-08 17:34

每當A股出現“窗口指導”，一般是市場某些領域出現了脱離正常情況的極端化，監管層才會實時的出來糾正，目的是為了讓市場迴歸正常化。

近期，A股出現“數板行情”，不是漲停板便是跌停板，在後續市場流出的信息來看，這種盤面現象直指：量化資金。

Image

### 1、量化機構開始”閉門謝客“

量化交易是指以先進的數學模型替代人為的主觀判斷，進行程序化交易，避免了人性對行情的主觀影響。這在港股、海外如美股市場常見，國內主要應用於在期貨、期權市場，但從2020年以來，在A股開始流行。

這種交易策略非常適用於T+0市場，但是給市場的波動很大，而在T+1市場同樣適用，能夠通過日內做T套利。同時，量化資金的策略前提是追求最大的確定性，注重強勢賽道的選擇，如果哪條賽道走勢市場最強，那麼就在那裏做高頻波段，用來實現收益最大化。

L12: 
L13: uSMART Securities Open API can provide API services for individual and institutional investor, investors can make full use of uSMART Securities trading services, quotes services, account services and so on to achieve their own investment applications.
L14: ## cite12†# How to apply Open API
L15: 
L16:   * Regular customers can apply through the following link：https://www.usmart.hk/zh-hk/open-api。
L17: 
L18:   * Due to limited service capabilities, the Open API service is only open to customers who have opened an account and have assets in uSMART Securities.
L19: 
L20:   * Using the Open API service to connect with uSMART Securities quotes requires programming foundation, and customers can consider whether to apply according to their own situation.
L21: ## cite13†# Open API custom development
L22: 
L23: uSMART Securities also provides Open API custom development services, the cost depends on the development workload. For customers with high hardware requirements, uSMART Securities can also provide server rental.
L24: ## cite14†# Open API account type
L25: 
L26: Open API account type is the same as the APP account type, and different account types enjoy different permissions, as follows:
L27: 
L28:   * Ordinary account: support U.S. stocks, Hong Kong stocks and A-share tradings, margin function supports some stocks, support option trading, account types include margin account and cash account, and orders can only be placed during trading hours.
L29:   * PRO account: Support U.S. stocks, Hong Kong stocks and A-share tradings, account types include margin account and cash account, orders can be placed at any time, enjoy IPO privileges, investment advisory privileges and other services.

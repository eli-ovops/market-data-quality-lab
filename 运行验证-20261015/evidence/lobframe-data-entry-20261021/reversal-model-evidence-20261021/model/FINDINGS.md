## 1. 标签是成交与事件时间的联合结果；精确可执行定义仍存在歧义

[PDF p26，§7.1](https://arxiv.org/pdf/2502.18625v2#page=26)：先在投稿时间t0按初始买卖队列映射Figure4成交概率曲面，筛估计成交概率严格大于80%的订单，形成集合O，182,381单/一周。随后标签1要求订单实际成交于T，且第一次成交后价格变化时T′≥T的有符号收益为正；不成交或不满足收益条件均标签0。因此它同时预测“会成交且随后有利”，不是只在已成交单上预测方向。

时间轴为 `t0：特征/筛选/预测 → 等待成交T（或未成交） → 首次成交后变价T′ → 形成标签`。预测期限为随机事件时间，含等待成交，不是固定1秒、5秒或60秒；§7.3 Table3另报自成交起5秒收益，不得当成训练标签期限。[PDF pp26、29](https://arxiv.org/pdf/2502.18625v2#page=26)。未来T、T′与实际成交是标签组成，论文声明输入已在t0可见；仅凭标签用未来信息不能指控输入泄漏。

必须保留的歧义：PDF和HTML都印出 `sgn(o)·(p(o)/p[T′]−1)·10000>0`，sgn买+1/卖−1。这按字面在买入后报价上升时为负，与“有利价格漂移”叙述反向。紧接公式先定义p[T′]为买单对应未来best bid、卖单对应未来best ask，下一段又称next midprice；T′第一次“price change”和“midprice change”的措辞也未完全统一。不能静默倒转比值或自选mid/bid/ask声称复现作者标签；真实实施采用何种定义为UNKNOWN。

## 2. 输入和系数部分公开，但不足以复原同一个预测器

[PDF pp26–28、32，§7.1/7.2/7.4](https://arxiv.org/pdf/2502.18625v2#page=27)：主模型是logistic regression，random forest为比较模型，不是DeepLOB。173维由以下组成：

- 5种历史时间尺度100ms/1s/5s/30s/300s，每种3个连续不重叠窗口，各有2项价格特征、6项成交数量/次数特征、3项动量特征，共165维。
- 最近100/500个10秒成交价收益的标准差，共2维，约16.67/83.33分钟历史。
- 6项盘口状态：最优买卖流动性、各侧执行50万美元的VWAP与最优价距离(bp)、过去10分钟最优价存活时长均值、距最近最优价变化的秒数。

输入需要成交逐笔价格/数量/方向、历史及盘口深度，只有十档快照本身不足以直接计算全部特征；50万美元深度是否在某市场十档内可覆盖也不能预设。买卖/买卖盘口按订单方向变换为同向/反向、近侧/对侧；部分收益再按方向乘符号。各窗口在同一尺度内互不重叠，不代表不同订单样本互不重叠。

§7.4明确所有变量估计前标准化；§7.2的“不需额外预处理/降维”不能解释成未标准化。[Appendix B Table5，PDF pp42–46](https://arxiv.org/pdf/2502.18625v2#page=42)确实列173个特征系数，已逐项文本解析并与HTML对照。没有列α0截距，也未公开这173维的训练均值/尺度、标准化拟合样本范围、方差约定/零方差处理。窗口边界、空窗口、收益/自协方差估计细节、方向变换逐特征规则、缺失数据规则等也没有达到确定重建输入的程度。随机森林结构/树参数及已拟合模型不在这些已读部分公开。

logistic公式印为 `P=1/(1+exp(α0+Σαi xi))`，即指数没有常见写法的负号；不能未经确认改成另一符号约定再套系数。特征命名还存在正文与表中的不同写法，如top_bid_liq/ob_bid_liq、ob_bid_half/ob_half、trade_intensity/avg_time_tr/velocity_tr等。故能复制算法框架和表列斜率，不能用现有文档保证复制原概率或阈值决策。

## 3. 只有同周前后半划分；85%不是所训模型准确率，没有公开AUC数值

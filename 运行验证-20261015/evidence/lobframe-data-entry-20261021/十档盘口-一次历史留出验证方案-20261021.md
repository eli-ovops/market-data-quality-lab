## 2. 因果输入、目标与样本

全部以供应商`local_timestamp`为时间基准，不冒充本机收到时刻。精确相同时间戳的多行合并为最后状态；不做十档状态相同去重。没有股票交易时段过滤，没有将美元价格截成整数。

决策t为UTC00:05起的固定网格。训练、验证每10秒；测试每120秒至23:53，共715个候选决策/测试日。所有模型在同一网格比较。测试的未来目标区间互不重叠，100状态历史输入窗不保证互不重叠；不能把相关窗口视为独立重复。

输入仅用采集时间不晚于t的最近100条合并状态。最后状态距t超过1秒、历史100状态相邻间隔超过2秒、正数/有限值/顺序/字段不合格时，属于当时可知的无信号条件，记录而不下虚拟决策。输入窗必须同一UTC日，不跨训练/验证/测试边界。

40列按每档`ask价格、ask数量、bid价格、bid数量`交错；量的原单位为BTC。价格特征取`log(price / 当时已知最后状态mid)`；数量取`log1p(BTC amount)`。输入逐列统计在固定训练样本全部100状态单元上计算（重复进入不同窗口的状态按各次单元计入），采用总体标准差ddof=0，列标准差为0用1；A/B共用屏蔽前统计，A随后将第2—10档置0。先定义并冻结再读测试性能。目标缩放也只用训练目标的均值与总体标准差；目标标准差为0则技术停止。没有未来价格、目标或测试统计参与输入标准化。

目标固定为：

`tau_a = 首条local_timestamp >= t+1秒的合并状态，必须 <= t+2秒`

`tau_b = 首条local_timestamp >= t+61秒的合并状态，必须 <= t+62秒`

`y = 10000 × log(bid_1(tau_b) / ask_1(tau_a))`

不得向后搜索更有利报价；首条状态不合格或不存在就记目标缺失。未来路径有超过2秒的状态间隔、跨UTC日或未来盘口异常，记事后评估缺口，不插值。该目标是延迟后买卖报价比，不是可成交收益或真实回报。

**未来缺口掩码不准用于决定当时是否发信号。** 测试要先为全部当时可输入的网格生成预测并封存，再看未来标签/报价是否可核。预测误差可在共同可核样本上比较并披露分母；任何被选中虚拟交易缺少未来账，经济结果不可判定，不把该交易事后删除或当作没交易。

## 3. 两个模型、一个固定报价基准

- A：第一档4列价量历史；标准化后将第2—10档列置0。
- B：完整十档40列历史。
- C：不变报价基准，预测`10000 × log(当前bid_1 / 当前ask_1)`。它假定未来报价不变；不能把预测0另称同一个基准。

A/B使用相同40列输入形状、同一结构和初始随机种子。差异只能解释为**该模型与预算下新增深档输入的条件增量**；屏蔽改变有效参数参与情况，不能宣称普遍识别了纯信息价值。第一档数量已在A，不能再把B的全部收益简单叫挂单压力收益。

未来独立实现固定的DeepLOB启发式卷积＋LSTM回归器，不复制受限LOBFrame代码或适配器、不使用其权重。公开方法参考：[DeepLOB论文](https://arxiv.org/html/1808.03668v3)。下述结构是本方案的设计，不称论文逐层复现。

| 模块 | 本方案固定定义 |
|---|---|
| 输入 | batch×1×100×40 |
| 第1卷积块 | 1→32，核1×2/步长1×2；再两层32→32、核4×1/步长1；时间维保持100 |
| 第2卷积块 | 32→32，核1×2/步长1×2；再两层32→32、核4×1/步长1；时间维保持100 |
| 第3卷积块 | 32→32，核1×10/步长1；再两层32→32、核4×1/步长1；时间维保持100 |
| 时间padding | 4×1卷积总补3行，前1后2；宽度减半/合并卷积不补宽度；所有输入在决策时已知 |
| Inception 1 | 32→64核1×1，再64→64核3×1，时间same |
| Inception 2 | 32→64核1×1，再64→64核5×1，时间same |
| Inception 3 | 时间3×1最大池化/步长1/前后各1，再32→64核1×1 |
| 激活/归一化 | 卷积后LeakyReLU(0.01)再BatchNorm；无Dropout；不改变特征顺序 |
| 循环与输出 | 拼接为100×192；1层LSTM输入192、隐藏64，最后时间步接Linear64→1；无Softmax |

只有这两个模型各训练一次。随机种子20261021；构造A、B各自之前均重置种子，初始参数逐项相同，每epoch样本排列相同。CPU；float32；固定batch64、drop_last=False；Adam，lr=0.001、betas=(0.9,0.999)、eps=1e-8、weight_decay=0；标准化目标MSE；梯度范数裁剪1；固定20 epochs，仅最终权重。LSTM隐状态在各独立样本间重置，无跨样本携带。验证、测试、最终训练能力检查均使用eval、禁梯度；BatchNorm运行统计只在训练批次更新，验证和测试不更新。不选择最佳epoch、不早停、不更换输入或阈值。模型预测先反标准化为bp，再与C或经济门槛比较；报告原单位MSE（bp²）。

若训练/验证产生NaN、资源超限，或任一模型最终训练误差不能优于训练目标均值基准，则技术/优化不充分，停止而不启用测试补救，也不能判定市场没有信息。最终训练误差须在全部固定训练样本上用eval统一计算，不用训练过程批次损失代替。预检检查模型形状、手算标签/费用、时间边界与未来字段隔离；这些检查不能替代预测与经济效果。

## 4. 封存与经济核算

先封存方案/实现哈希与训练输入，再训练并封存最终权重/训练统计。五个测试日先只生成、封存A/B全部预测、时点与输入来源标识，然后才统一评分。测试后不改模型、日期、指标、成本、门槛或信号规则，不换seed择优。

手续费固定情景为每边5/10/25/50bp，另有每边1bp额外不利滑点。**主情景是每边25bp、1秒引用延迟；5/10bp仅低费条件诊断，不因其最好而改主结论。** 增加同一封存信号的5秒引用延迟压力（买t+5后、卖t+65后首条，均最多等待1秒）；不重跑预测。各情景均是假设，不是已核个人费率。

信号规则：当预测报价log比大于对应双边手续费及滑点的精确log门槛时，才允许一笔假想多头；其余现金。阈值为`10000×log((1+s)(1+f)/((1−s)(1−f)))`。A/B和所有情景使用相同公式，无按测试收益调阈值。

每情景从虚拟$5,000现金、零BTC起步；五个测试日按时间顺序延续同一本现金账，不每日重置，日期之间空仓、现金不计息。每笔预算为当时现金的10%，上限$500，包含买入费用，不借款、不做空、不追加资本；持有期固定，不叠仓。买按未来快照前十档ask逐档数量核成本，卖按bid逐档核回款，另加既定不利滑点与双边费用。不能假定超过已见深度的数量也成交；若无法用十档核完整一笔，经济结果不可判定，不偷偷降规模或换价格。记录价格、数量、费用、现金及净值，不能只累计价差。每日损益为日末现金减日初现金；总体净损益为最后现金减$5,000，须等于五日损益之和。

风险口径固定：五个测试日各取UTC00:05至23:55的整分钟盯市网格。空仓时权益等于现金；持有时用该分钟不晚于该刻的最后完整十档bid，按同样费率与不利滑点核假想净变现价值，加剩余现金。该报价若超过1秒旧、十档不足以覆盖库存或有异常，则该持仓分钟风险缺价，经济风险比较不可判定，不插入未来报价。每日日内分钟权益log差为分钟收益；将五日全部日内分钟收益合并，以ddof=1标准差计风险，不年化、不把跨月间隔当一分钟。风险比定义为sd(B)/sd(A)，两者必须非零。最大回撤为按时间连接五日日内分钟权益后的峰谷比例；日期之间空仓现金延续。它是分钟采样回撤，不保证覆盖分钟内最深亏损；同口径适用于A/B，不能称所有风险均已匹配。

价差已体现在报价侧；深度核算不等于实际冲击已验证，未来快照不等于成交回执。转账、税、硬件、电力、人力等未核实项目单列UNKNOWN；不以0充当真实完整成本。该假想账只能回答条件经济效用，不足以证明个人全成本利润。

## 5. 通过、未通过、不可判定与停止

以下是事前候选筛选门槛，不是统计显著性或未来盈利保证。

**仅当全部满足，记“值得继续验证的历史候选”：**

1. 技术、时间与数据身份验收通过，预测/权重先封存；五个测试日全部可评，各日共同可核误差网格≥500。缺一天也不静默缩小分母，相关整体结论不可判定。无任何被选中虚拟交易的未来账/十档深度缺口。
2. 每日MSE为该日A/B/C共同可核网格的bp²误差均值；总体MSE为五个日MSE等权平均。B总体MSE低于A及C；至少4/5日B相对A的误差改善为正。报告各日及总体绝对差，相对改善以A误差作分母；分母0时相对量N/A。不能按有利日或样本数事后改权重。
3. 主成本情景B扣假设费用后净损益为正且高于A，B至少30笔完整平仓；逐日、总费用、最大回撤、持仓时间和交易数完整呈现。
4. 若声称经济表现优于A，A/B都须有上文定义的非零风险；风险比在0.8—1.25，且B分钟最大回撤不高于A。风险不匹配或所需盯市数据缺失，经济优劣记不可判定，不以改仓位补到通过。无仓时现金收益为0。

**分层判定：**预测增量与经济候选各记PASS/NOT_PASS/INDETERMINATE，最后合并，不让经济风险问题掩盖已有效检出的预测负结果。技术和预测数据充分时，未满足第2条就记预测NOT_PASS，不受风险是否匹配影响。经济账完整且B完整交易≥30时，主成本净损益非正，记主情景经济NOT_PASS，不需要先匹配风险。B正损益但风险不匹配/缺价，仅相对经济优劣INDETERMINATE；完整可比时未满足第3/4条，经济NOT_PASS。只有预测和经济均PASS才记值得继续验证的候选，其余关闭本配置追加实验或保留对应不可判定，不据此否定一切盘口模型。

只有低费情景正，不升级为主情景通过，也不能预设能拿到低费；不能因A或某压力格更好而事后改成本次推荐策略。

**不可判定：**样本/有效交易不足、风险不匹配、测试未来账或成交深度缺失、信息暴露核查出现无法排除的性能择优等。实际费率/本机延迟仍UNKNOWN时，即便历史候选通过，也不得称个人已可盈利。

# LOBFrame：从预测指标到净赚钱，还缺哪一段

核验日期：2026-10-21，约04:57—05:00 UTC。范围：既有LOBFrame方向，只读论文与公开源码、费用与行情文档。不开发实现，不运行模型或回测，不交易、不读凭证、不修连接，新增付款0。

## 结论

公开LOBFrame提供的是可研究的预测与简化交易模拟框架，当前证据不能支持“已有完整扣费后的盈利模型可以直接复制”。它确实能够扣双边比例手续费；关键缺口在成交真实性、延迟、冲击、完整资金账与特定代码路径的一致性。

本轮不是重复检查状态：完成了三个simulator文件与必要上游输出函数的静态执行链审计，并确认公开默认分支目前仍使用所审版本。这改变下一步：不能把仓库默认回测或论文的pT指标作为个人赚钱验收；若未来获准实验，需单独定义因果信号、真实报价侧、延迟和全成本的执行评估。本轮不启动该实验。

## 1. 论文究竟声称什么

本次原文是2024-06-04的arXiv v4，不能冒充2025期刊版本全文。§7.2明确讨论保证成交、零冲击与零成本等假设的不可靠性，转而提出交易信号序列的匹配指标。pT=CT/(PT+TT−CT)，比较目标序列与预测序列的开平点集合；它不是实际成交概率、净盈利胜率或投资回报率。作者提出这种指标，不等于给出了全成本实盘账。

来源：[论文v4 §7.2](https://arxiv.org/html/2403.09267v4#S7.SS2)。不因未提供盈利原账而否认该研究的预测与方法价值，也不把代码问题直接外推为论文所有数字失效。

## 4. 第一性原理下的下一步判断

假设模型预测短期价格上升，个人主动买入后卖出，钱来自有利价格变化；必须依次满足：判断有增量、在信息失效前成交、价差和全部费用后仍正、失误损失可控、留出期重复、资金扩大不吃掉边缘。模型分类指标只涉及其中一部分。

XTX研究讲座引用相关论文，并不意味着这些公开代码就是其生产模型。本轮也没有核到XTX实际预测准确率、净利润归因或可复制的私人权重。

当前唯一应保留的验证问题：十档盘口相对价格与价差，在事前定义的时间留出中，能否产生覆盖可落实费用和延迟的增量。若未来执行，不能直接采用上述有利报价挂单假设、错位概率或简化价差累计；应先通过数据/目标对齐与基本学习能力检查，再独立评价经济效用。未具备实际成本与时效边界前，不启动新的模型或账户实验，不靠换模型继续试到成功。

当前结论是研究候选，非赚钱项目。$5,000的资金规模不能补足不存在或未证明的边缘；扩大到更大资金与原财富目标仍缺重复净利、冲击与容量证据。不能据此作复利或达标年限外推。

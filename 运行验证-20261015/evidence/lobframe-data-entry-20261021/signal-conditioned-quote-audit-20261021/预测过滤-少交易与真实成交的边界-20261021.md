# 预测过滤挂单：改善究竟来自预测，还是少交易

结论：找到一个可读代码、派生研究表和事前规则文本较齐全的个人项目，但当前仍不能证明个人可复制的净优势。本轮有用的新证据是区分三个问题：信号过滤的增量、对称报价本身的模拟收益、真实延迟/队列下是否可得。它们的正负不能混在一起。本案不启动训练、回测或交易，也不转研究项目内其他机器人。该signal是既有盘口不平衡阈值，不是新发现的学习模型；本轮不据此恢复已关闭的单一挂单压力实验。

## 1. 信号过滤的改善尚未被隔离

[July研究表](https://github.com/Pablozh123/prediction-market-terminal/blob/1644347871bb568a614ba9a6a9634c224dc6799b/docs/research/mm_pnl_july-2026.md)在同一模拟下比较symmetric与signal。signal成交更少、总亏损减少，文中每成交的spread/markout没有显示改善；作者解释主要为少交易。不能把“亏得少”改写为已盈利，也不能从这组比较确定筛选比等量随机少交易更好。

已读[src/mm_pnl.py](https://github.com/Pablozh123/prediction-market-terminal/blob/1644347871bb568a614ba9a6a9634c224dc6799b/src/mm_pnl.py)的signal模式按当前盘口不平衡限制报价侧；没有取得等活动水平随机抑制对照。所以“只因少交易”是有表格支持的解释，而非已完成的严格因果归因。

代码还有一个解释限制：MMFill.mid_at_fill传入的是报价决策时quote_mid，而非实际成交时mid。其markout项包含等待成交期间的价格变化；不能称纯粹的成交后五分钟不利变价。spread+markout+late drift的总损益恒等式仍可以成立，恒等式通过不证明每个分量经济命名正确。详见code/静态核验报告。

## 4. 对个人复制的明确判断

可借鉴的一个环节是：检查信号是否在相同风险和活动水平下改善每笔净损益，避免把少交易或更少持仓造成的改善错认成预测优势。公开源码足以学习这一审查方法。

当前不复制此项目的整套做市，也不按其正数启动新模型。决定性缺口是实际可知数据与时钟、到达/撤单后队列及成交、全费用、总本金约束；本轮并未证明个人现有电脑速度不够、也未证明更快电脑就能赚钱。

只有独立数据及实现身份齐全，并在事前固定的可实现延迟、真实费用、统一本金下，预测过滤相对等活动水平基准仍有正增量，才有理由升级为个人候选。当前是新假设的证据要求，不是已完成试验或新执行许可；没有财富1%路径或资金容量证明。

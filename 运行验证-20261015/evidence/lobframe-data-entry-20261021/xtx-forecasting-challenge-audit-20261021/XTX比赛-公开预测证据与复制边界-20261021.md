# XTX预测比赛：能借鉴什么，不能证明什么

结论：确认了一个直接属于XTX的公开预测研究入口，但没有取得可直接复刻其交易优势的完整材料。比赛存在和获奖结果有XTX公开账号证据；预测目标细节、R²口径及方法只取得参赛者部分材料，不能升格为XTX生产策略。当前不按这套材料追加模型或交易验证，原STOP保持。

## 1. 官方公开到哪一层

[XTX企业账号招赛帖](https://www.linkedin.com/posts/xtx-markets_were-excited-to-launch-the-xtx-markets-global-activity-6551725372264845312-l8_k)说明举办Global Forecasting Challenge并提供奖金/招聘机会。[Gerko账号转述的企业结果帖](https://www.linkedin.com/posts/gerko_xtx-markets-global-forecasting-challenge-activity-6589883744369299456-anMA)公布前五及Under-25获奖者、超过10万美元奖金。它们确认比赛与奖项，不提供数值预测分数、完整获奖模型、逐笔成交或费用账。奖金不是交易利润，也不是参赛者或公司的投资回报率。

本轮公开页面只显示相对年份，未取得精确发布日期；2019赛事年份另由参赛者文字和赛事合作方公告线索支持，不把相对年份计算成已核准确时刻。读取日UTC2026-10-21。

比赛站原生读取不可达，源HTTP状态UNKNOWN；没有重试或修连接。精确原主办方repo correlation-one/XTXStarterKit的首次gh API请求HTTP404，停止该路径；不据此认定删除/私有/从未存在。官方完整规则、commit、许可、排行榜分数及最终测试工件当前未取得。

## 2. 一份参赛者材料提供了什么

只审[dushiyu个人仓库](https://github.com/dushiyu/Mid-price-Prediction-Based-on-High-Frequency-Data/blob/74493c54c452938cbd3c152eef2a8ca1187952ed/README.md)，固定commit74493c54c452938cbd3c152eef2a8ca1187952ed（2020-05-27）。以下均为作者说明或已读source，不是官方规则认证，也不是我们行情QC。

- 作者称输入约300万条记录、买卖各14档价量，目标为87 ticks后的mid变化。精确差分/比率、价格单位、端点/平滑定义未取得。
- notebook说明没有timestamp，实际以行号time:i处理。因此87指事件/记录步距离，不能说87秒、87毫秒或任何固定墙钟时长；也不能从中推出XTX生产预测期限。
- 只公开部分数据准备与历史特征；自称最终选用Random Forest on non-overlapping data，但未提供最终训练预测链、模型、分割边界、官方成绩或名次。winning model在这里不作获奖证明。

已读预处理有历史窗口/lag特征，不能据此认证未公开最终程序无泄漏。名为volatility/std的一列实际仍用均值公式，是列名与计算不符的静态事实；尚未证明它进入最终模型或影响官方成绩。

## 3. 一个值得复制的因果纪律

作者特别警告不能把past y当成下一条预测的已知输入。原因是y描述未来结果，即使放在数据表“上一行”，在当时也不一定已经揭晓。模型研究应按实际可知时刻组织输入，而非只看行号是否在前。

教学示例（不是比赛已核标签公式）：假设y_t由第t+87条价格决定，在第t+1条做决策时，第t条y仍包含未来。因此“用了过去一行”并不自动排除未来泄漏。该例没有运行数据或模型。

README自写R²表达式缺少预测残差项，不能当成一般样本外预测R²，更不能冒充官方评分。一般决定系数以1减残差平方和/目标离差平方和表示；本轮只作概念核对，没有重算分数。比赛的隐藏测试、时速和模型大小限制也只取得参与者陈述，未独立认证实际私有评分执行。

## 4. 对个人复制的决定

可以借鉴：以连续盘口事件构造历史特征；分清事件步与现实时间；防止延后揭晓的目标泄漏；把最终预测程序和评价数据身份封存。

尚不能复制为赚钱操作：没有精确目标与现实时间映射，就不能衡量信号活多久、网络延迟和费用能否覆盖；没有完整模型/官方分数工件，不能称复现获奖成绩；没有成交、库存、退出和费用，不能把R²或比赛名次写成净利。数据/软件的个人复用授权也不能由fork或公开可看自动推定。

本例当前收口为研究线索，不升级执行候选。它补充了XTX确实使用公开预测挑战筛选人才的证据，但没有公开其生产模型的准确率、期限、参数或利润贡献。旧模型不重开，不转年度配置、清算或其他赛事，也不等待作者回复。原财富目标仍未取得可验证的达成路径。

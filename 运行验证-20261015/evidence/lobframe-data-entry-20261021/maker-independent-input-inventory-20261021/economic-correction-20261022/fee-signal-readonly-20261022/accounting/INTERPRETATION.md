# 会计桥对判断的影响

1. **5月这四条保存路径有毛现金余量，但费用超过余量。** F的G分别约1.5196、2.6592、3.6726、1.3702USD，对应显式费用约4.5875、7.2598、37.4821、43.5745USD，N均负。这支持“固定路径毛现金被显式费用抵消”，不支持“本来已有预测alpha”；G还混有库存、时机和成交组成。
2. **6月不能只怪手续费。** F四格G约−2.1481、−1.4639、−5.5606、−8.5258USD；即使机械加回全部显式手续费，这些保存路径也仍负。并未重跑零费率策略，其资金/订单/成交可能不同，不能把这里外推为真实零费策略结果。
3. **相对H的优势也不统一。** 全8格ΔG只有May X100和Jun X500为正，这只是8格描述，不是独立胜率或显著性。May X500的ΔG约−1.0589、ΔC约−2.1784，最后ΔN约+1.1195：净额较H少亏主要因显式费用少，不能说费前选择更好。Jun X500的ΔG约+1.1617、ΔC约−2.0959、ΔN约+3.2576，但F净额仍约−114.9546USD。

这些固定路径算术足以否定“所有格仅因费高而亏”的统一解释，也不足支持“信号完全没信息”的相反断言。旧D是不同提示集合不利变动的条件差，当前ΔG是两条完整政策路径的毛现金差，不能互相替代。风险可比和库存/执行价格分项归因仍UNKNOWN，不能把G或ΔG命名为纯价差、因果alpha或个人收益。

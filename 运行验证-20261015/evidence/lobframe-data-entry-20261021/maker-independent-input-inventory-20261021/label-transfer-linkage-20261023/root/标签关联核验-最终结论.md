## 1. 事前固定了什么

- 输入仅旧两日coverage和独立库存退出两日ledger，四源各顺读一次并同时核封存SHA/字节/行数与gzip EOF/CRC；保留两日×四情景×F1/H1的全部16路径。
- 精确键为日期+tradeID；原外部被动订单ID不等于本人虚拟订单ID。先技术身份/方向/保存钟核，再继承被引用记录本身的旧selected_first/reference_qualified标签；不拿同ID别处首次标签移给后来成交。
- 主统计逐日逐情景取F/H同价买入所引用的支持打印并集；跨臂打印去重，再按原外部buy_order_id去重；保持原打印grid、grid内ID等权、有效grid等权。多ID不分配本人fill量，跨情景不当独立复制。
- 比较原成交流提示应避开买侧(z_buy)与原时间哈希提示应避开买侧(hash_buy)的旧1秒不利变动均值；D_buy=L_z−L_hash，正号仅表示原风险识别方向同向。只买侧，不乘半、不补sell、不冒称原双侧D复现，不做置信区间或第二种择优判定。
- A为全部同价唯一引用tradeID中的技术匹配比例；B为技术确认外部买订单ID中，其原首次合格标签确实落入支持集合的比例。二者均至少80%，两主组各至少100不同外部ID，才具备本次描述性迁移资格。原各类失败保留分母；不因结果稀疏降低门槛。
- 穿价cross一律不可转移旧loss；冻结只共同严格前缀，全窗UNKNOWN。时间目标、费用、退出和旧现金均不改。

## 4. 能确定的与仍未知的

**已确定：关联流程没有被大量ID或旧标签缺失卡住。** 精确身份覆盖高，选定的同价支持记录确实能追溯到旧标签。直接把前轮亏损归因为“标签都没接上”没有证据支持。但这不认证旧源全市场无缺口、真实双钟/到所、独立raw同价核验或模型真实获单。

**已确定：原风险对比人口没有足量留在这个已成交支持集合。** 合格ID有9至35个，但原z_buy/hash_buy组只有0至3个；标签可用和风险对比组齐全是两件事。不能把23个标签齐全写成有23个风险提示组样本，也不能把空组均值填0。

**解释而非已证明因果：** 策略本来会暂停其提示危险的一侧；排队、撤单、到所、库存约束与主动退出又继续筛选哪些买单真的在模型中成交。所以只看已成交买单，原来“本应避开的机会”可能已很少出现。这与结果相容，但本轮没有隔离各筛选环节，不能据此证明过滤器成功避免了多少亏损，或认定所有风险信息失效。未成交、被取消和未模拟拿到的订单没有由本单补造自身标签。

**仍未知：** 旧条件信息是否足以迁移到模型整条可获买入路径；cross的对应风险、未成交对照、各环节因果作用、真实获单/费用后优势与容量。旧1秒参考目标也不同于原1+2δ到龄退出、实际卖价和费用。即使小样本D为正，也不补成正毛利或净利。

## 2. 退出规则：一个时钟、一个版本

**选择1秒的理由：** 沿用原短期风险研究的1秒尺度作一次可解释挑战，不按已见净额优化；批次时钟从自身模型买入fill开始，与原网格标签目标并不相同，也没有证据证明1秒最佳。方案中不试5秒、10秒等备选。

### 2.1 批次与正常卖出

每次maker买入fill（含部分成交）建立一批：数量、模型接收时刻b、唯一fill序号及余量；到期d=b+1秒。同刻按原处理序号。所有普通maker卖、年龄退出、日终退出统一按“先买先出”（FIFO）扣同一份批次余量，不按价格或未来收益挑库存。任何时刻批次余量之和=BTC；已卖部分不得再次退出。

maker新单仍固定q。**只有新增年龄退出可卖不足q的剩余批次量**，用于明确处理部分成交；这不是调整入场q，也不认证现实交易所最小订单金额/取整允许该量。

### 2.2 触发、撤单、发送、成交

1. 最早有余量的批次到期时，建立一个退出事务，暂停新maker提交并请求撤销两侧全部未完单。已有撤单不延期；原在途接受/成交/取消继续按原固定次序处理，预留不得提前释放。新买fill如发生，照常入批次账，不凭空消失。
2. 触发时刻记d*（首次就是d；若排在另一退出之后则为当时真实可处理时刻，不回溯），固定等原δ=100或500ms，至τ=d*+δ。到τ，屏障前订单/预留必须已关闭；否则实现失败。汇总此时已到期且仍未卖出的量Q，冻结其FIFO分配并预留，不提前扣BTC。Q=0则在τ释放屏障，不发送exit、不扣成交费；严格晚于τ的下一整秒才恢复原F/H maker提交，不能同刻重挂或额外等待不存在的u。未到期批次原timer保留，若其间到期照规则启动下一事务。
3. Q>0时在τ发送退出意图，再等同一δ，于u=d*+2δ到达。发送后不得增量、换批次或按新价格重挑库存；后到期量留下一事务。全程仍暂停新maker提交。首次批次最快约买入后1.2秒或2.0秒退出，**不是保证持仓1秒**。
4. 到u才用原严格在先参考：capture<u、source<u、年龄≤1秒、完整且无原冲突；最新无效不向前挑另一价格。用该组bid25按最优到最深卖固定Q，每档价不利1bp、每腿扣0.004。先确认整笔容量足够，再原子记入各腿；不能只退出好卖部分后抹掉余量。
5. 每路径对同一快照capture组共享有限退出深度预算，年龄退出和日终都扣。跨退出不能重装同组深度；只有严格更新capture组才可按新组原amount重置。记录row身份及逐档before/used/after。新组重置仍是无市场冲击的条件模型，不能认证真实补量或容量；旧maker打印/队列不获得额外虚构补量。
6. 参考缺失、冲突或剩余深度不足：保留首个UNKNOWN、全部现金/库存/预留，不等待后继好价、不用未来价或mid补足，不把未成交意图记成无成本成功。该路径的完整退出/净现金不可认证；不丢该格。输入身份、重复成交、超卖或守恒错误则整单首失败停。
7. 成功后扣已冻结批次量和退出预算、释放预留，逐腿费用与现金守恒。已有新到期量则从当前u启动下一事务；没有则到严格晚于u的下一整秒才恢复原F/H。不能立即抢回旧队位。

退出锁定期间，原共同整秒网格的decision、安全状态及F/H原始暂停信号仍照算照记，仅新maker提交被屏障阻断，日志单列阻断原因；不能跳过网格改变提示预算。

两侧暂停及取消是退出事务的必要互斥约束，不另改F/H原信号。它会改变后续入场、资金占用和成交集合；所以新旧净现金差是**完整政策变化**，不能说成“相同成交下的纯退出alpha”。

### 2.3 同刻事件和日终接管

同capture固定：原活跃单print批处理→批次到期/建立屏障→原cancel/TTL（cancel先于accept）→既有退出到达、τ发送→其余原accept→原网格决策。普通卖先发生时按FIFO扣减，发送只锁实际剩余；已发量不因同刻新增批次扩大。无新退出事件的时刻保持旧排序。pending单不能越过已生效撤单复活。

09:00:50及以后不新启年龄事务、不发送新年龄退出；未发送余量交原日终。50秒前已发出的退出不作无成本撤销，仍按u到达（最迟早于50.5秒）；若50秒同刻到达则先处理该到达，再终端接管。所有maker原样全撤。09:00:51原清仓前必须确认maker/exit无未完预留；按原51秒严格参考，否则仅等至52秒首个合格参考，清全部余量并扣共享深度和费用。已卖批次不双卖，无法闭合则UNKNOWN，不延期/换窗口。

完整模型费用不等于个人真实全成本。个人实际费率/最低费用、最小订单、运营、时间、税费、真实路由延迟/冲击与获单仍UNKNOWN；本单不据此算实际ROI、容量或复利财富路径。

## 4. 风险可比性：两种比较分开

### 4.1 新F1与新H1：保留原风险门槛

两臂均须无现金/库存/预留限额违例。原每网格及成交/动作后的观察时点保持，新增退出观察原子前和全部腿后，不用腿间虚假估值峰值。

三个风险指标都须完整可判：①BTC数量×秒积分；②按原bid25毛变现口径的最大库存美元名义；③按原深度、1bp不利及0.004卖费净权益的最大回撤。逐指标要求F1≤H1，相等允许；不放宽为容差、不按成交数配平、不调资金比例，不把“不高于”说成严格风险匹配。

持BTC的必需估值若缺严格asof/≤1秒fresh/完整深度或有原冲突，则相关价格风险UNKNOWN，库存与现金保留；纯现金权益仍可知。不得插值、使用后继价、删持仓观察或把局部max当完整max。

**新退出深度与原风险估值的一致性：** 原估值公式和观察时点不改。若BTC>0，且该次风险参考快照组已被本路径年龄/日终退出实际耗过量，不能重新用未经消耗的fullbook认证可执行风险；该价格风险观察记UNKNOWN，不另开发剩余深度估值/界估计来救结果。它是模型一致性限制，不等于行情断线或已证明风险更高。若发生，不晋级，但已知负现金仍可独立判失败。

### 4.2 新政策相对旧政策：不能补造风险匹配

旧F0/H0的价格风险仍UNKNOWN，旧表局部最大值不可用于配平。新旧现金差仍可描述，但“在相近风险下优于旧政策”继续UNKNOWN。即使新F1/H1自身三风险可判并满足原门槛，也只能保留**新政策在两日同样本内的条件模型候选**，不能自动认证相对旧F0的同风险优越。

## 5. 通过、失败、不可判定和停止

**候选通过：** 八格逐格全部同时满足：

- 执行、FIFO/预留、已建模费用及最终清仓完整，账式精确闭合；
- ΠF1>0、ΠF1−ΠH1>0，且ΠF1−ΠF0>0（旧F0已负，正新现金自然蕴含这一点）；
- 原共同限额无违例，新F1/H1三风险完整可判且逐项F1≤H1。

只保留上述有限候选，不承诺个人能成交、完整个人净盈利、稳定优势或容量。H1是否比H0好必须报告，不临时加“H也必须改善”等新门槛。库存减少只是机制描述；利润不能靠把余仓留着不卖。

|情况|结论与停止动作|
|---|---|
|任一格完整ΠF1≤0，或双方完整且ΠF1−ΠH1≤0|现金必要条件失败，停止此固定退出版本晋级；不能因少亏/库存小称通过，风险状态另列|
|现金条件均过，但任何新风险UNKNOWN|现金必要条件过、风险未识别，不晋级；不补价/换口径/延长freshness|
|新风险可判但F1任一项>H1|原风险条件不满足，停止晋级；不事后降低仓位配平|
|年龄/日终退出参考或深度不足，现金无法闭合|该格净现金UNKNOWN，保留首缺口；不把它当正/负结果或剔除后报成功；本次不晋级|
|身份/时序/超卖/重复耗深度/守恒错误、资源超限|整单首失败STOP，保存现场，不修后择优重跑|

任何正式结果出后不换年龄阈值、日期、情景、费用或模型。必要的适配/合成修正只在正式前完成；正式一次，无中间成绩挑参。若这个版本只降低库存但未满足必要经济条件，就停止该具体版本，不自动试另一个退出。

## 2. 批次FIFO账：一份库存、不能重复卖

每次maker买fill（包括部分fill）新建独立lot：唯一buy-fill序号、fill时刻b、初始量v、剩余量r=v、到期d=b+1秒；同capture买fill按原固定处理次序的fill序号排序。FIFO顺序固定为(b,fill序号)，不按价格/未来收益挑库存。原maker卖fill、下述年龄退出、日终退出都从同一FIFO列表扣量；卖出不另建“负lot”。始终assert sum(r)=BTC、r≥0、总卖量≤总买量，现金/费用沿原exact Decimal守恒。

maker卖单预留仍是总可用BTC，不专属锁定特定lot；其fill按FIFO扣。lot到期前已被maker卖完，保留审计记录、其timer无动作；部分卖后只对剩余r处理。新taker退出可以小于q，正是独立库存退出，不改变maker新单仍固定q。

## 3. 一个退出屏障，两个原延迟，无额外择时

退出锁定期间共同网格及F/H原信号照算照记，只阻止maker新提交，不删除网格或改变原提示预算。

1. 最早仍有r>0的lot到期d时，启动一个退出屏障：禁止新maker提交，给当前两侧全部pending/active/cancel-in-flight单发撤单请求，reason=inventory_age_exit。已有cancel_at不延期/重发；pending接受也不能释放预留或漏过撤单。撤两侧是为了释放卖预留并阻断新买单，属于退出附带动作，不改F/H信号本身。
2. 屏障固定发送时刻τ=d+δ，δ仍仅100或500ms；即使当时没有冲突单或已有撤单更早完成，也不提前退出。其间原maker打印/部分fill、原接受/撤单竞态继续，原现金/BTC预留不提前释放；在途新买fill照常建自己的lot，不能当作“已退出”。
3. τ=d+δ时所有屏障前未完单必须已关闭，若还有未释放订单/预留则实现状态失败，不强抢卖预留。此时合并所有d_i≤τ且r_i>0的到期lot，冻结发送量Q_exit及其FIFO lot分配，并以独立exit_reservation预留该量（不提前减BTC）。发送退出意图后不可增量或重新挑lot；后续才到期的lot记入下一批。Q_exit=0则于τ释放屏障，不发送exit、不扣费；严格晚于τ的下一整秒才恢复原F/H maker提交，不能同刻恢复，也不额外等待不存在的u。未到期lot的原timer保留，若恢复提交前已到期，按正常规则进入下一屏障。
4. Q_exit>0时，退出意图再经历同一δ，固定到达u=τ+δ=d+2δ；不是即时taker成交，也不是新增第三档时延。发送到到达期间继续禁止新maker单；原maker已在τ前全部关闭，不能与退出预留竞争。到u才取唯一严格asof参考（完整最新capture<u、source<u、年龄≤1秒，最新无效不回退），以bid25档逐档卖固定Q_exit，价格不利1bp，每腿taker .004。队列/时钟仍是supplier名义点模型，不声称实测到所或真实成交。
5. **同row有限预算。** 每路径独立维护exit_book_key=(snapshot组capture,原始row身份)及25档退出剩余量。第一次选择该组时，预算=该组各bid原amount；同一组再次被年龄退出或日终退出选中，先前这些退出已用量逐档扣除，绝不重新装满。只有选中严格更新的snapshot capture组才重置为新组原amount（不是同组不同引用/行号就重置）；冲突组仍无效。同一次退出预先验证整笔Q_exit在剩余预算内，再按最优到最深各档实际用量扣减，记录before/used/after。maker打印队列与成交不新增这份退出预算、不替它补量；不重构旧maker队列，也不认证新快照真实补量、隐藏流动性或个人容量。
6. 参考缺失/冲突、预算深度不足或状态矛盾：不等后继更好报价、不改价、不部分卖后丢残量；保留现金/lot/exit预留及首UNKNOWN见证，停止该路径经济晋级（最终现金不能闭合则UNKNOWN）。不能取消已发意图后当作成功无成交，也不略过该退出继续。身份/输入错误按首失败停，不据结果修后重跑。已闭合标量仍分别报告。
7. 成功到达后按发送时冻结的FIFO lot分配扣Q_exit，释放exit预留，逐腿保留cash/qty/notional/fee；原子前/全部腿后风险观察，不每腿复用完整旧深度。若等待期间新lot已到期，在u成交后的同一事件阶段开始下一屏障，其基准触发时刻改为u（不回溯下单），再等δ发固定量、再等δ到达；不把它补进本次已发送量。否则解除锁，到严格晚于u的下一整秒网格才恢复原F/H提交。部分lot未到期保留自己的timer，不等全库存满1秒才处理。

所有退出量预留必须进入总sell-reserved invariant，且exit在途时不能再由maker/另一个exit预留或卖出同一lot；lot余量之和仍等于BTC，exit预留只是其子集。新快照重置只是一种固定有限条件模型；不是对市场实际补给的认证。深度预算用于退出模块（含日终）的成交可用量，不给旧maker队列增加任何假造差分或队前消退。原风险清算估值口径保持并标明它与实际退出消耗预算不同；若因此不能声称可比，则风险UNKNOWN，不能凭正现金晋级。

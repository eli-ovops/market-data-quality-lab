## 2. 仅增加一种压力规则，固定四情景

|执行规则|100ms|500ms|
|---|---|---|
|E：原仅同价打印耗队列|E100|E500|
|X：同价如E，另纳入严格穿价打印压力|X100|X500|

E完全继承原同价规则，结果单列。X两臂使用相同规则：对原guard合格、处于模型活跃期的每个唯一打印trade，主动买(type0)与己方卖单相容，主动卖(type1)与己方买单相容。记己方限价L、打印价P、正打印量v、剩余量r、旧队前量a：

- **同价P=L**：仍先消耗a，只有超出a的打印量可填己方，最多r；部分成交保留剩余状态。原depth减量不得给队列进度。
- **严格穿价**：卖单遇主动买且P>L，或买单遇主动卖且P<L，按己方限价L填 `min(r,v)`；不以更有利打印价成交。不先用v扣旧a：此压力规则显式假设严格穿价已经跨过该限价的旧队前量，因而忽略旧a，并将a置0；若部分成交，剩余r继续活跃、a保持0。
- **不相容/未达限价**：不耗该单队列、不fill。best bid/ask移动或碰价、盘口减量本身均不得产生无量fill。不把一笔穿价print变为整单无限量fill。

每条打印在每个“政策×情景”的独立路径中只分配一次：同价与穿价分支互斥；队前消耗与自身fill共用同一v，不重复扣/使用。每侧最多一张，打印不能再用于已填完的单；剩余打印量不带到未来新单。重复tradeID绝不重耗。F/H及四情景是平行反事实模型，允许各自使用同一外生事件，但不把跨臂使用误称现实中拥有多份市场成交。

该穿价假设用于暴露仅同价可能遗漏的坏成交，**不是已证FIFO、真实个人获单下界或利润保守界**；加入穿价也可能改变好成交、库存和后续报价。少fill不等于利润保守，E正不能直接认证净利；X也不能冒称成熟引擎完整复刻。只借MIT已审局部机制作参照，保留许可，不引入完整默认引擎、不安装依赖。

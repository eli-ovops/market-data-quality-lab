# 从信号到收益：F/H成交、撤单、库存和退出诊断

**结论：只保留“库存退出”这一个后续验证环节。** 当前代码管理的是每张报价何时撤掉，没有独立管理买入后何时、以什么约束减仓。固定单量又使不足一单的尾量不能常规挂卖。这是已确认的结构，库存持续和终端残量也有原账支持；但它尚未被证明是亏损主因，更没有证明改后能赚钱。当前固定组合不晋级，旧8格F扣费净额均负、价格风险可比性UNKNOWN和STOP保持。

这里的F是按过去1秒成交流暂停一侧；H是在同一非零提示网格按固定时间哈希暂停一侧的无成交流信息对照。不是XTX的公开策略，也不是实际个人成交。E为仅同价成交模型，X另计严格穿价压力；100/500ms是固定假设延迟，不是个人实测。

## 3. 用一个格解释转换问题，同时保留反例

June X100：F接受27,738张模型订单，其中640张有过maker成交（675行）；H为26,036张、610张（636行）。F并非简单地少成交。

F累计maker买入0.205494736792 BTC、卖出0.185016826001 BTC，差额0.020477910791 BTC留到终端；H相应为0.189919329271、0.188620887963，终端0.001298441308 BTC。恒等式说明买卖未在过程内完全闭合，**不说明这些未闭合库存具体亏了多少钱**。

该格F/H终端卖出额约1490.99/94.54美元，显式退出费5.96/0.38美元。F比H净额差−8.74美元，其中已可识别的显式总费用差约+8.24美元，另有同一已存路径加回费后的毛现金差约−0.50美元。额外终端费约5.59美元属于总费用差的一部分，不能与其重复相加，更不能把卖出1490.99美元当作损失。

但June E500是重要反例：F终端只余约0.186q，卖出额9.21美元、退出费0.037美元，净额仍约−5.36美元。因此不能把全部失败归咎于尾量或终端退出。

## 5. 唯一后续环节：独立库存退出

**已知事实：** 报价1秒撤销不等于持仓1秒退出；F/H共用短报价、固定q、现货和终端清仓结构；库存与终端数量有实际原账支撑。

**工作假设：** 即使入场侧风险提示有信息，反复报价本身未保证买入后可按相同短周期逻辑卖出，所承担的库存风险与付费可能掩盖小的风险筛选好处。这是值得局部检验的转换假设，尚非因果结论；信号强度不足和执行假设不实仍未排除。

**为什么只选它：** 它是具体、可定位且可以复用缓存的问题，不需要更强模型/付费新数据。更快撤单和更准确队列虽也可能重要，但现账没有其有利反事实或个人实测证据，不同时开第二支线。

**能否低成本解决：** 对固定q、退出状态和现金记账做一个预先定义的局部比较，在技术上可能低成本；真正解决利润未知。只补不足q卖单不能处理全部≥q存量，不能认定为充分修复。风险参考缺口也不会因退出代码改变自动消失；若保持UNKNOWN，只能定位机制，不能通过盈利/风险可比性验证。

**如果以后验证，唯一问题是：** 让已成交库存具有独立于开仓暂停信号的退出约束，是否在不靠增大风险的前提下改善完整模型扣费现金？应先固定一个版本，保留F/H、原两日四情景、原费用及终端强制清仓，不挑格/窗口，不靠把余仓留在账上隐藏损失，不临时降低费用。比较库存/终端依赖和F相对H的已建模费用后净现金增量；个人真实全成本仍待独立证据。最终仍须原经济必要条件（各预定格F净额>0且F−H>0）和可判的风险条件，不能仅靠库存减少或少亏晋级。具体规则/参数、执行和资源审批不属于本轮，尚未制定或运行。

**当前决定：继续一个库存退出机制的有限求证有研究价值；停止将当前固定组合推进为赚钱方案。** 不泛化为全部做市/成交流信号无效，也不把继续诊断当作已有可赚钱候选。没有新数据、规则修改、策略或模型重跑、连接账户、交易或新增费用。

## 为什么不可判定，不能一概怪数据

1. **风险参考有缺口。** 在有BTC库存时，部分时点没有满足预定一秒新鲜度及严格时序的合格报价，不能按统一可执行退出口径完整计量回撤和最大风险。没有因风险估值参考缺失将已知库存或在途单归零，但局部风险值不能认证全路径风险。全部16条路径及8格比较保留UNKNOWN。最后能卖出，不证明中途风险已完整测量。
2. **当前执行模型的价区限制。** `accepted_price_outside25`指实现没有为部分拟接受价格定义队前量；它不是交易所实际ack。Root定点复核core.py129–136并经独审确认，该实现要求订单价在同侧25档最高/最低价之间，连价差内部的改善报价也可能被排除。因此其中既可能有真正更深价位的输入不足，也有冻结模型域较窄的限制，不能全归因于必须买更深L2/L3。没有逐事件重读当时book，不知道实际两类比例，不据此改填单或重跑。
3. **收益来源未拆出可靠结论。** 暴露期间共同参考不足，报价相对价贡献与库存价格漂移的分项归因全部UNKNOWN。不能把条件分支现金差归为“避开坏成交赚的钱”，也不能说只是BTC上涨。即使F曾少亏，也不是稳定预测优势证明。

这些限制在结果中保留，没有为了得到答案放宽新鲜度、价区、费率或风险门槛。原正式单元到此终止。

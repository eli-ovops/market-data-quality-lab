L406: Order Book
L407: The order book channel sends the new ask and bid orders for the given market in batches, every 50ms. While the nonce is tied to Lighter's matching engine, the offset is tied to the API servers; hence, you can expect the offset to change drastically on reconnection if you're routed to a different server. Regardless, on each update the offset will increase, but it's not guaranteed to be continuous. Additionally, this channel sends a complete snapshot on subscription, but only state changes after that.
L408: To verify the continuity of the data, you can check that `begin_nonce` on the current update matches the `nonce` (i.e. `last_nonce`) of the previous update.
L409: [Button: JSON]
L410: 
L411:     `{
L412:         "type": "subscribe",
L413:         "channel": "order_book/{MARKET_INDEX}"
L414:     }`

L646: Binary Options Market Stats
L647: Subscribe to `bo_market_stats/{MARKET_INDEX}` for one market or `bo_market_stats/all` for all binary options markets. The all-market response contains a `bo_market_stats` object keyed by market ID; a single-market response contains one stats object. The all-market stream also includes old, settled and not-yet-open markets: filter by `status: "active"`, then check the trading window and `is_frozen` in cite19†events before placing orders. See cite20†Binary options WebSocket for fields and lifecycle statuses.

L726: Candlesticks
L727: 
L728: Real-time candlestick (OHLCV) updates via WebSocket. Subscribe to any market and resolution to receive live candle data as trades occur. Supported resolutions: `1m`, `5m`, `15m`, `30m`, `1h`, `4h`, `12h`, `1d`. The candles[] array allows up to 2 candles to be sent in a single update when a candle period closes (rolls over). If so, candles[0] will be the oldest, just closed candle.
L729: [Button: JSON]
L730: 
L731:     `{
L732:     	"type": "subscribe",
L733:     	"channel": "candle/{market_id}/{resolution}"
L734:     }`
L735: 
L736: Example Subscription
L737: 
L738: [Button: JSON]
L739: 
L740:     `{
L741:     	"type": "subscribe",
L742:     	"channel": "candle/0/1m"
L743:     }`
